# Archive

Historical record of how the book was produced. Nothing here is read by the site or by any
current editorial process — it's kept for traceability, not maintained going forward.

| Folder      | Contents                                                                 |
| ----------- | ------------------------------------------------------------------------- |
| `raw/`      | Raw ChatGPT and Gemini drafts for every chapter, before synthesis         |
| `prompts/`  | Every generation and editorial-pass prompt used to produce the book       |
| `notes/`    | Scratchpad calibration notes from the voice, wife, kids, and orientation editorial passes (all four passes are complete across all 90 chapters) |

Paths referenced inside these files reflect the repo layout at the time they were written —
before the part folders' `README.md` files were renamed to `index.md` and `raw/`/`prompts/`
moved under `archive/`. Treat them as a historical snapshot, not a live reference.
